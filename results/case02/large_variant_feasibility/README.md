Archived evidence for the EB-NeRD large-variant feasibility check of Case 02: `ebnerd_feasibility.py` as run on 2026-10-14 (Codex card K5, commit 4fb21ff), its output `k5_feasibility.log`, and the timings transcribed from the K5 run report into `timing.json`.
The script is archived evidence, not maintained code: it is kept byte for byte as run and is not linted, tested or updated.
It needs the EB-NeRD large raw files (`data/raw/ebnerd_large`), which the licence keeps out of the repository, so the run cannot be repeated from a clone alone.
The report that cites these files is `case_studies/02_metric_that_told_two_stories/large_variant_check.md`.
